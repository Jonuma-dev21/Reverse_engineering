# Reverse Engineering — Practical Labs & Documentation

**Cybersecurity | Reverse Engineering | Binary Analysis | Low-Level Programming**

## About this repository

This repository documents my practical work in Reverse Engineering as part of my cybersecurity learning journey.

It brings together a collection of technical exercises, experiments and analysis reports organized into five sessions. Each session explores different techniques for understanding executable files, analyzing program behavior and investigating how software works internally.

The main objective is to develop a deeper understanding of binary structures, compilation mechanisms, memory, program execution and software security.

## Learning Areas

Throughout these sessions, I explore several aspects of Reverse Engineering:

- **ELF Analysis:** Understanding executable file structures and ELF mechanisms.
- **Static Analysis:** Examining binary files without executing them.
- **Dynamic Analysis:** Observing program behavior during execution.
- **String Analysis:** Investigating strings and identifying techniques used to hide or manipulate them.
- **Linking Mechanisms:** Exploring static linking, dynamic linking and the Global Offset Table (GOT).
- **Binary Decompilation:** Understanding program logic through disassembly and decompilation.
- **Program Analysis:** Investigating executable behavior through practical challenges and exercises.
